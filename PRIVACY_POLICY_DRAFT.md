# TableSnap Privacy Policy (MVP draft)

**Effective date:** [Insert publication date]

TableSnap is designed to process images selected by you on your Android device to extract table text and create spreadsheet files.

## Information processing

In this MVP, the image you select is processed on your device using Google ML Kit's on-device text recognition libraries. TableSnap does not operate an image-upload server and does not intentionally transmit your selected images or extracted table contents to the developer.

Exported spreadsheet files are saved only to a location you select through Android's system document picker.

## Permissions

TableSnap uses Android's system picker to let you select an image and Android's document picker to save an exported file. It does not request broad access to photos or shared storage.

## Changes to this policy

If future versions add analytics, crash reporting, advertising, cloud processing, accounts, or purchases, this policy and the Google Play Data safety disclosures must be updated before those features are released.
