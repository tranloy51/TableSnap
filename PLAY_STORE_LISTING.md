# TableSnap — Google Play Store Listing

## App name
TableSnap: Image to Excel

## Short description
Turn table photos into editable spreadsheets. Export to Excel or CSV.

## Full description
Turn tables in screenshots and photos into spreadsheets with TableSnap.

TableSnap helps you extract text from a table image, review the result, make corrections, and export your work as an Excel or CSV file. It is designed for quick, practical conversion when you need to reuse information trapped inside an image.

**HOW IT WORKS**
1. Choose a screenshot or photo containing a table.
2. Let on-device text recognition read the image.
3. Review and edit the extracted rows and cells.
4. Export your table as an Excel (.xlsx) or CSV (.csv) file.

**KEY FEATURES**
• Image-to-table workflow: start with a screenshot or photo.
• On-device OCR: recognize supported text without uploading your selected image to a TableSnap server.
• Editable results: correct cell contents and adjust your table before exporting.
• Excel and CSV export: save a spreadsheet file to a location you choose.
• Multiple scripts: supports Latin, Chinese, Devanagari, Japanese and Korean text recognition.
• Simple, focused interface: import, review, edit and export in one app.

**PLEASE NOTE**
OCR results depend on image quality, text size, layout and language. Complex, handwritten, rotated or poorly lit tables may require manual corrections. Always review extracted data before using or sharing it.

TableSnap does not require an account to use its core features.
